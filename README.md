# Документация к модулю «Генератор паролей»

## Назначение

Модуль позволяет генерировать случайные пароли с настраиваемыми параметрами
(длина, используемые типы символов) и оценивать их сложность (надёжность).

## Описание функций

### 1. `generatePassword(int length, boolean useUpper, boolean useLower, boolean useDigits, boolean useSpecial)`

Генерирует один случайный пароль заданной длины из выбранных типов символов.

- **Вход:**
    - `length` — желаемая длина пароля (целое число, > 0);
    - `useUpper` — включать заглавные латинские буквы (A–Z);
    - `useLower` — включать строчные латинские буквы (a–z);
    - `useDigits` — включать цифры (0–9);
    - `useSpecial` — включать специальные символы (`!@#$%^&*()-_=+[]{}`).
- **Выход:** `String` — сгенерированный пароль.
- **Исключения:** `IllegalArgumentException`, если `length <= 0` или не выбран ни один тип символов.

### 2. `generateMultiplePasswords(int count, int length, boolean useUpper, boolean useLower, boolean useDigits, boolean useSpecial)`

Генерирует список из нескольких паролей с одинаковыми параметрами.

- **Вход:** `count` — количество паролей; остальные параметры — как у `generatePassword`.
- **Выход:** `List<String>` — список сгенерированных паролей.

### 3. `containsUpperCase(String password)`

Проверяет, содержит ли пароль хотя бы одну заглавную букву.

- **Вход:** `password` — проверяемая строка.
- **Выход:** `boolean` — `true`, если найдена заглавная буква.

### 4. `containsDigit(String password)`

Проверяет, содержит ли пароль хотя бы одну цифру.

- **Вход:** `password` — проверяемая строка.
- **Выход:** `boolean` — `true`, если найдена цифра.

### 5. `containsSpecialChar(String password)`

Проверяет, содержит ли пароль хотя бы один специальный символ.

- **Вход:** `password` — проверяемая строка.
- **Выход:** `boolean` — `true`, если найден специальный символ.

### 6. `checkPasswordStrength(String password)`

Оценивает сложность пароля по 4 критериям (верхний регистр, нижний регистр,
цифры, спецсимволы) и его длине.

- **Вход:** `password` — проверяемая строка.
- **Выход:** `String` — одна из оценок: `"Слабый"`, `"Средний"`, `"Сильный"`.
- **Правила:**
    - длина < 8 символов → `"Слабый"`;
    - длина ≥ 8 и выполнено ≥ 3 из 4 критериев → `"Сильный"`;
    - длина ≥ 8 и выполнено < 3 из 4 критериев → `"Средний"`.

## Примечания для тестировщика

- В модуле есть одна преднамеренная ошибка (согласно заданию практической
  работы). Она не задокументирована здесь специально — её нужно найти с
  помощью модульных тестов.
- Рекомендуется обратить особое внимание на граничные случаи: пароли ровно
  8 символов, пароли без каких-либо спецсимволов, пароли с разными наборами
  специальных символов.
- Стиль кода: camelCase для методов и переменных, Javadoc-комментарии к
  каждому публичному методу.
